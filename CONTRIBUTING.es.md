# Cómo contribuir

Gracias por ayudar a construir una oficina virtual para todos.

1. Haz un fork del repositorio y crea una rama para tu cambio.
2. Ejecuta `npm ci` y `npm run dev` para probarlo, y `npm test && npm run build` antes de abrir un pull request.
3. Mantén el comportamiento fiel a la experiencia de una oficina real y documenta cualquier decisión visual o de interacción en `docs/COMPARACION-GATHER-2.md`.
4. Las traducciones son muy bienvenidas: los textos de la interfaz están en `src/i18n/`.

Los issues y pull requests pueden escribirse en español o en inglés.
