# Contributing

Thanks for helping build a virtual office for everyone.

1. Fork the repository and create a branch for your change.
2. Run `npm ci` and `npm run dev` to try it, and `npm test && npm run build` before opening a pull request.
3. Keep the behaviour faithful to a real office experience, and document any visual or interaction decision in `docs/COMPARACION-GATHER-2.md`.
4. Translations are very welcome: interface strings live in `src/i18n/`.

Issues and pull requests are welcome in English or Spanish.
