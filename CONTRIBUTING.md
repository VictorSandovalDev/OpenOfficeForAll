# Contributing · Contribuir

Thanks for helping build a virtual office for everyone. · Gracias por ayudar a construir una oficina virtual para todos.

1. Fork the repository and create a branch for your change.
2. Run `npm ci`, `npm run dev` to try it, and `npm test && npm run build` before opening a pull request.
3. Keep the behaviour faithful to a real office experience; document any visual or interaction decision in `docs/COMPARACION-GATHER-2.md`.
4. Translations are very welcome: every interface string lives in `src/App.tsx` and `src/VivoScene.tsx`.

Issues and pull requests in English or Spanish are both fine. · Los issues y pull requests pueden ir en inglés o en español.
